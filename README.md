# ☕ coffeeJava

> 대구 지역 카페를 중심으로 한 리뷰 기반 커뮤니티 플랫폼

대구 지역 카페를 중심으로 한 리뷰 기반 커뮤니티 플랫폼입니다.
사용자가 직접 카페 리뷰를 작성하고, 댓글과 좋아요를 통해 다른 사용자들과 소통할 수 있는 커뮤니티 서비스를 목표로 개발했습니다.

---

# 📌 프로젝트 소개

최근 지역 기반 카페 탐방 문화가 활발해지면서, 단순 SNS 후기보다 더 구조적이고 체계적인 리뷰 공유 플랫폼의 필요성을 느꼈습니다.

coffeeJava는 대구 지역 카페를 중심으로,

* 카페 리뷰 작성
* 평점 기반 정보 공유
* 댓글 및 좋아요를 통한 소통
* 신고 및 관리자 기능

등을 제공하는 커뮤니티 플랫폼입니다.

본 프로젝트는 프론트엔드 없이 DB 설계 및 백엔드 API 구현에 집중하여 진행했습니다.

# 🔐 비밀번호 찾기 이메일 인증 구현

비밀번호 재설정 기능은 총 3개의 API 흐름으로 구성했습니다.

1. 이메일 인증 코드 발송
2. 인증 코드 확인
3. 비밀번호 변경

### 1️⃣ 이메일 인증 요청

* 입력받은 email로 user 테이블 조회
* 회원 정보가 존재하지 않아도

  ```
  요청이 정상적으로 처리되었습니다. (이메일을 확인해주세요)
  ```

  메시지를 반환하도록 구현

→ 존재 여부를 노출하지 않도록 하여 보안 측면을 고려했습니다.

* 회원 정보가 존재하는 경우 auth 테이블에 인증 코드 저장
* 동일 user_id의 기존 인증 코드는 모두 사용 처리
* 가장 최근에 생성된 인증 코드만 유효하도록 설계

---

### 2️⃣ 인증 코드 검증

* 이메일로 전달된 인증 코드 확인
* 인증 성공 시 해당 코드를 사용 처리
* 재사용이 불가능하도록 구현

---

### 3️⃣ 비밀번호 변경

* 인증 완료 여부 확인
* 새로운 비밀번호로 변경

---

# 🧩 구현 과정에서 겪은 문제

### 📍 email 값 전달 오류

초기에는 email 값이 `""` 를 포함한 상태로 전달되어 지속적으로 예외가 발생했습니다.

요청 데이터 검증 및 문자열 처리 로직을 수정하여 해결했습니다.

---

### 📍 SMTP 설정 문제

초기에는 Gmail SMTP를 사용하려 했지만,
앱 비밀번호 설정 문제로 인해 메일 발송이 정상적으로 동작하지 않았습니다.

이후 네이버 SMTP로 변경하여 구현했고,
네이버 SMTP 사용 설정이 반드시 필요하다는 점을 확인했습니다.
